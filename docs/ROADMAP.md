# 待办、边界与验收标准

这是接力任务池，不是当前执行授权。标记“未验证”不等同已确认漏洞，“明确限制”不等同必须牺牲保护才能修复。基准见 [HANDOFF](../HANDOFF.md)。

## 优先P0：真实只读兼容性（CLIENT-06，未关闭）

现状：已切换WBI字幕/播放和一次受限字幕备用；离线通过，真实账号链路未验。浏览器登录未完成验收，登录事务按用户要求暂停。

建议拆分：
1. 获明确只读授权和安全凭据配置，确认账号，不回显Cookie/token；保持writes_enabled=false。
2. 分别验证搜索、视频、评论、主/备用字幕、公共媒体下载；无字幕/鉴权/风控要独立结果，不把所有失败当无字幕。
3. 记录实际status/code、是否触发暂停、命中哪个路径；URL auth_key等签名参数不进报告。
4. 若接口形状不符，先脱敏fixture+失败测试再改，不先放松host/redirect/风控限制。

验收：只读操作得到真实且可复现结果，风险/空数据如实报告，保护仍有效。未真实触发的备用路径继续写“未验证”，不为凑验收故意制造风险。

## 优先P1：人工登录接力产品化

现状：remote_browser是原机Linux运维脚本，非原生插件登录功能。客户端Windows通过SSH隧道，用户尚未验收完整接入。浏览器vault、浏览器profile、插件secret scope独立。

任务：参数化解释器/Chromium路径/UID/display/端口，增加用户接管状态、超时/停止入口、session仍在才恢复操作；安全登录态桥接另行设计和授权。

验收：在新机器按文档可启动；实际IPv4/IPv6无VNC TCP监听、noVNC/CDP仅loopback、Origin拒绝测试、Xauth/socket权限、真实退出清理/故障回归；用户完成CAPTCHA，模型不代解。浏览器完成登录不误报插件已认证。持久数据不自动清除、不上传。

## 优先P1：安全操作员诊断与在途锁恢复

现状：强杀留下dispatch_guard后所有真实派发被阻止，resume不清锁。没有安全恢复UI/命令。

任务：首先做只读诊断（request/operation/时间/状态/暂停），再设计明确用户动作与审计记录，研究如何证明旧请求已结束、保留未知发送状态。

验收：绝不能仅按过期时间抢锁；不能让模型清锁；不能把清锁等同unknown可重发；模拟原进程仍在、POST已成功但落库中断、无remote_id、双进程竞争等场景。实现前讨论风险，不附通用删SQL“修复”。

## 优先P2：用户可见的阅读能力

### 一键视频阅读报告

输入BV，汇总元数据/字幕时间点/评论分歧/可选画面采样/信息缺口。链接实际evidence_id，区分事实、来源观点、模型推断；字幕缺失时不可编造内容。验收包括无字幕/抽帧失败/预算不足/恶意字幕提示等降级；不需要外发。

### UP主更新与主题日报

先只读更新源、去重、已读游标与候选排序，再整合现有周期/记忆。验收：重启不会重复读/发，预算计每个HTTP，运行中断明确状态；不隐式启动监听或cron。

### 反馈闭环与管理

把用户反馈关联BV、证据与草稿/推荐理由；支持检索、导出和审计。private内容不自动进入公开报告，导出需用户选范围。改变偏好不伪造历史事实。

## 优先P2：资源/存储加固

- 媒体全局跨目录/并发配额：先原子预约/完成/中断回收设计，不只扫描一次目录宣称强配额。
- OS文件/CPU/内存沙箱：在保留协议/本地下载限制基础上增加隔离，不把mov格式限制说成OS沙箱。
- 硬总deadline：当前剩余socket+块间检查不保证DNS/open/TLS总墙钟。若需要严格上限，考虑可终止进程边界和不明结果语义，不只循环check时钟。
- schema升级/备份：现为version1已知布局迁移；新增版本需旧库fixture、拒绝未知/坏列、完整备份和失败保留，不删账本重置。
- cycle/state跨库一致性：目前证据和完成副本不是跨库原子事务；有warning/失败边界，未来若增强先补崩溃点回归。
